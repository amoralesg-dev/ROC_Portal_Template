# @rassini/rassini-ui Documentation

Bienvenido a la documentación oficial técnica de la librería corporativa **rassini-ui**.

Esta carpeta contiene todas las guías certificadas y auditadas necesarias para ensamblar un portal protegido, implementar autenticación y pintar el sistema de diseño corporativo. Ningún archivo requiere que abras el código fuente de la librería.

### Documentos Principales
- [QUICK_START.md](./QUICK_START.md): Guía lineal, a prueba de balas, para ensamblar un portal desde cero y hacerlo compilar.
- [ARCHITECTURE.md](./ARCHITECTURE.md): Explicación de fronteras. Qué hace la librería, qué hace el consumidor y qué hace la API.
- [INSTALL.md](./INSTALL.md): Detalles manuales sobre comandos de instalación y providers de Angular requeridos.
- [AUTHENTICATION.md](./AUTHENTICATION.md): Cómo funciona internamente la sesión, el token JWT, el LocalStorage y el reinicio por F5.
- [AUTHORIZATION.md](./AUTHORIZATION.md): Cómo proteger rutas usando `permissionGuard` y el diccionario de permisos base.
- [COMPONENTS.md](./COMPONENTS.md): Catálogo de componentes públicos (`rui-login`, `rui-shell`, `app-data-table`, etc).
- [EXAMPLES.md](./EXAMPLES.md): Ejemplos puros de código de integración real del *Employee Portal*.
- [TROUBLESHOOTING.md](./TROUBLESHOOTING.md): ¿Tienes un error infinito? ¿Te sale NG8002? Resuélvelo aquí.
- [MIGRATION_GUIDE.md](./MIGRATION_GUIDE.md): Cómo versionar, generar `.tgz` y migrar a versiones futuras.
- [CHANGELOG.md](./CHANGELOG.md): Historial de cambios técnicos.
- [GLOSSARY.md](./GLOSSARY.md): Glosario de términos.
- [JUNIOR_ONBOARDING_CHECKLIST.md](./JUNIOR_ONBOARDING_CHECKLIST.md): Cuestionario para certificar que estás listo para desarrollar.

### Validación y Certificación
- [VALIDATION_REPORT.md](./VALIDATION_REPORT.md): Certificado oficial que avala la auditoría de exports y la compilación real del framework.
